# Security reports

**This is an unmaintained, one-off community release. No versions receive ongoing security support. No response, fix, or future compatibility update is promised.**

Private vulnerability reporting is enabled. If GitHub’s [private reporting form](https://github.com/davehillm/bricksbuilder-component-thumbnails/security/advisories/new) is available, use it for suspected vulnerabilities. Do not post credentials, private source captures, or an exploitable vulnerability in a public issue. Archiving may limit interaction with the repository; do not rely on a report being reviewed.

Include the affected plugin version, WordPress/PHP/Bricks versions, the required account permissions, and steps to reproduce. Share a minimal example without customer content when possible.

The tested environment is Bricks 2.4.4, WordPress 7.1.4, and PHP 8.3. The adapter permits Bricks 2.4.x; broader compatibility has not been established. The [final review](SECURITY-REVIEW.md) is a point-in-time assessment, not a security guarantee.

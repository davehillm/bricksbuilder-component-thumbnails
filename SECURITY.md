# Security reports

Please report suspected vulnerabilities through [GitHub’s private vulnerability reporting](https://github.com/davehillm/bricksbuilder-component-thumbnails/security/advisories/new). Do not post credentials, private source captures, or an exploitable vulnerability in a public issue.

Include the affected plugin version, WordPress/PHP/Bricks versions, the required account permissions, and steps to reproduce. Share a minimal example without customer content when possible.

Compatibility is currently scoped to Bricks 2.4.x. Use the latest release and review the release notes before updating. This community project does not promise a fixed response time or security support period.
